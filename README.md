# AI-DLC Panel

**AI-DLC 워크플로가 지금 어디까지 왔고, 다음에 무엇을 해야 하는지를 IDE 안에서 한눈에 보여주는 패널입니다.**

터미널 로그나 상태 파일을 직접 뒤지지 않아도, Activity Bar의 **AI-DLC** 아이콘 하나로 진행 상황·산출물·검토 현황을 확인하고 다음 작업을 이어갈 수 있습니다. 패널은 엔진 상태를 **읽기 전용**으로만 읽습니다. 여러분의 워크플로 파일을 건드리거나 바꾸지 않으니 안심하고 켜 두세요.

## 이 패널로 할 수 있는 일

- **지금 위치 파악** — 전체 진척도와 현재 Phase·Stage, 다음에 할 일을 요약해서 봅니다.
- **산출물 검토** — 각 단계가 만든 파일을 열어 확인하고, 검토 완료를 표시하고, git 이전 상태와 비교합니다.
- **질의응답에 바로 답하기** — `*-questions.md`를 전용 질문 화면에서 열고, 선택지를 클릭하면 즉시 답변을 저장합니다. 직접 입력 영역을 선택하거나 내용을 입력하면 해당 내용을 답변으로 자동 저장하며 별도 반영 버튼이 필요하지 않습니다.
- **승인 대기 확인** — 워크플로가 여러분의 승인을 기다리면 알림과 상태 표시줄로 알려 줍니다.
- **바로 이어가기** — 버튼 한 번으로 새 세션에서 워크플로를 이어서 진행합니다.
- **Kiro에 검토 요청** — 산출물을 Kiro에게 검토해 달라고 바로 요청합니다.
- **되짚어 보기** — 규칙·지식·질의응답·활동 이력을 읽기 전용으로 탐색합니다.

## 시작하기

1. 확장을 설치합니다(팀에서 받은 `.vsix` 파일을 **Extensions 뷰 → `...` → Install from VSIX...** 로 설치하거나, 아래 [개발 · 배포](#개발--배포)의 CLI 명령을 사용).
2. 설치 후 **Developer: Reload Window** 를 실행합니다.
3. AI-DLC 워크스페이스(폴더 어딘가에 `.kiro/tools/aidlc-lib.ts` 가 있는 프로젝트)를 엽니다.
4. 왼쪽 Activity Bar에서 **AI-DLC** 아이콘을 클릭합니다.

> 최초 활성화 시, 패널이 상태를 읽는 데 필요한 읽기 전용 도구(`panel-model.ts`)를 워크스페이스의 `.kiro/tools/`에 자동으로 설치합니다. 별도 설정은 필요 없습니다.

**필요한 것**

- **VS Code `^1.74.0`** 또는 Kiro IDE
- **[bun](https://bun.sh)** — 상태를 읽는 도구를 실행합니다. `bun`이 PATH에 있어야 합니다.
- **AI-DLC 워크스페이스** — 열린 폴더 중 하나에 `.kiro/tools/aidlc-lib.ts`가 있어야 패널이 켜집니다. 멀티루트 워크스페이스에서는 엔진이 있는 폴더를 자동으로 찾습니다.

## 화면 구성

**AI-DLC** 아이콘을 열면 여섯 개의 뷰가 나타납니다.

- **현황** — 활성 Intent, 전체 진척도, 산출물 검토 진행바, 다음 할 일, 검토가 남은 산출물을 요약합니다. 패널을 열면 가장 먼저 보이는 화면입니다.
- **작업(Actions)** — 자주 쓰는 버튼 모음입니다: 이어서 진행하기(새 세션) / Kiro에 물어보기 / Intent 전환 / 파킹·재개 / 전체 대시보드 / 새로고침. 뷰 제목 표시줄에서 언어도 바꿀 수 있습니다.
- **진행 단계** — Phase → Stage 트리로 각 단계의 상태(완료·진행 중·승인 대기·수정 중·대기·건너뜀)를 보여 줍니다. 단계를 클릭하면 상세 패널이 열려 "이 단계에서 확인할 내용 / 이 단계의 목표", 산출물 검토 현황, 실행 이력 타임라인을 볼 수 있습니다.
- **산출물 · 검토** — 단계별로 만들어진 파일을 모아 봅니다. 검토 완료 표시/해제, 검토 진행 개수, git HEAD 대비 **변경/신규 배지**, 변경 비교, Kiro에 검토 요청을 제공합니다.
- **참조 · 이력** — 규칙 메모리, 코드 지식(codekb), 팀 지식, 질의응답, 관찰 일지, 활동 이력을 읽기 전용으로 둘러봅니다.
- **팁 · 도움말** — Scope, 확장 사용법, AI-DLC v2 사용법 팁을 접이식 섹션으로 제공합니다.

## 자주 하는 작업

### 이어서 진행하기

**작업(Actions)** 의 **이어서 진행하기** 버튼을 누르면 새 Kiro 세션에서 `/aidlc` 이어가기를 요청합니다. 엔진이 활성 Intent를 해석해 마지막 체크포인트에서 바로 이어갑니다.

### 승인 대기 알림

워크플로가 게이트(승인 대기)에 도달하면 상태 표시줄에 `⏳ 승인 대기: <단계>`가 표시되고 알림이 한 번 뜹니다. 알림의 **단계 열기**를 누르면 해당 단계 상세로 바로 이동합니다.

### Kiro에 검토 요청

산출물 항목이나 단계 상세에서 **Kiro에 검토 요청**을 누르면:

1. 대상 파일을 에디터에 열어 Kiro 채팅의 컨텍스트로 만들고,
2. **새 Kiro 세션**을 연 뒤 검토 프롬프트를 전달합니다.

새 세션을 여는 명령은 Kiro/VS Code 빌드마다 다를 수 있어 런타임에 후보 명령을 탐지해 사용합니다. 어떤 명령이 인식되는지 확인하려면 명령 팔레트에서 **AI-DLC: 채팅 명령 탐지**를 실행하세요. (새 세션 명령이 없는 빌드에서는 현재 채팅을 재사용합니다.)

### 진행 단계 토글

**진행 단계** 뷰 제목 표시줄에서 다음을 접거나 펼칠 수 있습니다.

- **완료 단계 접기 / 표시** — 이미 완료된 단계를 숨겨 남은 작업에 집중합니다.
- **건너뛴 단계 접기 / 표시** — 현재 Scope에서 제외(SKIP)된 단계를 숨깁니다.

토글 상태는 워크스페이스별로 저장됩니다.

## 주요 명령

명령 팔레트(`Ctrl/Cmd+Shift+P`)에서 사용할 수 있는 명령입니다.

| 명령 | 설명 |
| --- | --- |
| `AI-DLC: 새로고침` | 상태를 다시 읽습니다. |
| `AI-DLC: Intent 전환` | 활성 Intent를 변경합니다. |
| `AI-DLC: 파킹 / 재개` | 워크플로를 안전하게 중단/재개합니다. |
| `AI-DLC: 전체 대시보드 열기` | `aidlc-dashboard.ts`로 HTML 대시보드를 생성해 엽니다. |
| `AI-DLC: Kiro에 물어보기` | 현재 단계 컨텍스트로 새 Kiro 세션을 엽니다. |
| `AI-DLC: 이어서 진행하기 (새 세션)` | 워크플로 이어가기를 새 Kiro 세션에 요청합니다. |
| `AI-DLC: 채팅 명령 탐지` | 이 빌드에서 인식되는 채팅/새 세션 명령을 보고합니다. |
| `AI-DLC: 패널 초기화 (모델 도구 설치)` | 모델 도구를 재설치하고 새로고침합니다. |

## 동작 방식

- 상태는 `aidlc/spaces/<space>/intents/<intent>/aidlc-state.md`와 스테이지 그래프에서 **읽기만** 합니다. 엔진 파일은 절대 수정하지 않습니다.
- `aidlc/**/{aidlc-state.md,active-intent}`와 `aidlc/active-space`를 감시해 변경 시 자동으로 새로고침합니다.
- 검토 완료 표시와 토글 상태는 VS Code 워크스페이스 저장소(Memento)에 보관됩니다.

## 개발 · 배포

> 이 아래는 확장을 직접 빌드하거나 팀에 배포하는 사람을 위한 내용입니다. 단순히 사용만 한다면 위 [시작하기](#시작하기)로 충분합니다.

### 소스에서 개발 실행

```bash
cd aidlc-panel
npm install
npm run compile
```

이후 VS Code에서 `aidlc-panel` 폴더를 열고 `F5`(Run Extension)를 눌러 Extension Development Host에서 실행합니다.

### VSIX 만들기

```bash
cd aidlc-panel
npm install
npx @vscode/vsce package --allow-missing-repository --skip-license
# -> aidlc-panel-<version>.vsix 생성
```

버전은 `package.json`의 `version`을 올린 뒤 다시 패키징하세요. (설치본은 버전이 올라가야 갱신됩니다.)

### 나눠주기 · 설치

- 생성된 `aidlc-panel-<version>.vsix` 파일을 공유(사내 저장소, 채팅, 공유 드라이브 등)합니다.
- 받는 사람은 CLI 또는 UI로 설치합니다.

```bash
kiro --install-extension aidlc-panel-<version>.vsix --force
# VS Code면: code --install-extension aidlc-panel-<version>.vsix --force
```

또는 UI: Extensions 뷰 → `...` 메뉴 → **Install from VSIX...** 로 선택. 설치 후 **Developer: Reload Window** 를 실행해야 새 버전이 활성화됩니다.

- 사내 갤러리(Open VSX 프라이빗/Azure DevOps 등)가 있다면 `vsce publish`로 올려 자동 업데이트를 받을 수도 있습니다. 없으면 VSIX 수동 배포가 가장 간단합니다.
- 받는 사람도 요구 사항(bun, AI-DLC 워크스페이스)을 충족해야 정상 동작합니다.

## 변경 이력

> `0.4.0`을 기준선으로, 그 이후 추가·수정된 내용을 주제별로 모아 정리합니다. (버전별로 나누지 않습니다. 아직 버전을 나눠 배포한 이력이 없어, 세분화된 버전 구분은 사용자에게 의미가 없기 때문입니다.) AI-DLC 고유어(Phase·Stage 이름, `Intent`, `Scope`, `Bolt` 등)는 한국어 화면에서도 규칙에 따라 영어를 유지합니다.

### 0.4.0 (기준선)

- **최초 구성** — AI-DLC 엔진 상태를 **읽기 전용**으로 표시하는 Activity Bar 패널.
- **뷰 구성** — 현황 / 진행 단계(Phase→Stage 트리, 단계 상세 패널, 감사 로그 기반 실행 이력 타임라인) / 산출물·검토(검토 표시·해제, git 대비 변경·신규 배지, 변경 비교) / 참조·이력 / 팁·도움말.
- **워크플로 지원** — 승인 대기 상태 표시줄·알림, 완료·건너뜀 단계 토글, Kiro에 검토 요청(새 세션), 전체 대시보드 생성, 파킹·재개, 최초 활성화 시 읽기 전용 모델 도구 자동 설치.

### 0.4.0 이후 추가·수정된 내용

**뷰 · 기능**

- **작업(Actions) 뷰 신설** — 워크플로 실행 버튼(이어서 진행하기 / Kiro에 물어보기 / Intent 전환 / 파킹·재개 / 전체 대시보드 / 새로고침)을 현황 뷰에서 분리해 전용 뷰로 제공합니다.
- **산출물 편집 명령 추가** — 산출물 항목에서 파일을 바로 편집하는 명령(`editArtifact`)을 추가했습니다.

**다국어 · 언어**

- **한국어 UI(현지화)** — 번역 번들(`l10n/`), 명령·뷰 이름 현지화(`package.nls`), 라벨 헬퍼(`labels.ts`)로 한국어 UI를 지원합니다.
- **패널 언어 수동 전환** — `AI-DLC: 언어 설정` 명령(English / 한국어 / 자동)과 커스텀 i18n 런타임(`i18n.ts`)으로, IDE 언어와 별개로 패널 언어를 직접 고를 수 있습니다.
- **번역 누락 보완** — 하드코딩되어 있던 문자열을 모두 번역 경로(`t()`)로 전환했습니다(관찰 일지 배지, 트리 명령 제목, 모델 로드 오류 메시지, `consumes`의 "(선택)" 표기, 단계 상세의 "Stage → 단계", 누락됐던 뷰 제목 등).

**산출물 · 검토**

- **질의응답(Q&A) 표시 정리** — `*-questions.md`를 필수 산출물로 유지하되, 대화 아이콘과 미응답/응답 배지로 질의응답임을 구분하고 중복 노출을 없앴습니다. "질의응답·일지 표시/숨기기" 필터의 적용을 받습니다.
- **질의응답을 검토 집계에서 제외** — 질의응답은 "검토"가 아니라 "응답" 대상이므로, 검토됨/총계·검토 대기·단계 상세 검토바 집계에서 제외해 영구 미검토로 남던 문제를 해결했습니다.
- **질의응답 직접 처리 화면** — 질문별 선택지와 직접 입력을 한 화면에서 제공하고, 현재 답변과 답변 저장 상태를 표시합니다. 선택지 클릭은 즉시 반영되며 직접 입력은 입력 중에도 직접입력 답변으로 판단해 자동 저장합니다. 기존의 별도 **답변 반영** 버튼은 제거했습니다.

**워크플로 동작**

- **"이어서 진행하기"로 정리** — 모호하던 "다음 단계 실행" 라벨을 **이어서 진행하기**로 바꾸고, 클릭 시 `/aidlc`를 그대로 전달해 엔진이 활성 Intent를 해석하고 체크포인트에서 바로 이어가도록 단순화했습니다.
- **모두 건너뛴 Phase 표시 구분** — 한 Phase의 모든 단계가 SKIP된 경우 `0%` 대신 `—` / `— 모두 건너뜀`으로 표시해 "진척 0%"와 시각적으로 구분합니다.

**성능 · 안정성**

- **모델·git 호출 비동기화** — 상태 모델(`bun`)과 git 조회를 동기(`spawnSync`)에서 비동기(`spawn`)로 전환해 UI 스레드 블로킹을 제거하고, 오래된 결과가 최신 결과를 덮어쓰지 않도록 시퀀스 가드를 추가했습니다.
- **셸 호출 강화** — git/bun 호출을 문자열 조합(`shell:true`)에서 인자 배열(`shell:false`)로 바꿔 경로 따옴표·주입 위험을 제거했습니다.

**문서 · 링크**

- **팁 참고 문서 링크 교체** — 팁의 공식 가이드 링크를 **AI-DLC v2 공식 레포 문서**(`awslabs/aidlc-workflows`, <https://awslabs.github.io/aidlc-workflows/>)로 바꾸고, Phase·Scope 세부 가이드 링크를 추가했습니다.

## 라이선스

AI-DLC 엔진 상태를 읽기만 하며 변경하지 않는 내부 애드온입니다.
